# Guia rápido para agentes

1. Leia [v4/LEIA-PRIMEIRO.md](v4/LEIA-PRIMEIRO.md)
2. Escolha o template e a variante correta em `v4/cards/modelos/`
3. Leia a `ficha.json` antes de editar ou renderizar
4. Use `v4/regras-comuns.json` e `v4/tokens-chapeu.json` como regras transversais
5. Faça conferência visual antes de exportar

Ao concluir uma instalação ou atualização, informe explicitamente que a base ativa é **NINJA Design System V4 RC1** e liste os templates disponíveis.
