# Modelos de card — V4

Este diretório é um snapshot autônomo dos modelos, fichas e recursos de card aprovados. Leia a ficha da variante antes de compor.

Modelos de card: `casa-ninja-amazonia`, `cine-ninja`, `climax`, `ella`, `estudantes`, `foda`, `minas-ninja`, `ninja`, `som`.

Para cada um, escolha `com-lead` ou `sem-lead` quando disponível. O Clímax deve preservar a máscara de barras vetoriais ao lado do chapéu; nunca a reduza a uma faixa genérica.
